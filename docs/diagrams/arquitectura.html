La arquitectura, capa por capa

Cada capa cumple una responsabilidad distinta. El diagrama la explica con una descripción breve y un ejemplo de uso en la aplicación.

Código contrastado: 25 de octubre de 2026 · alcance implementado: niveles 1 y 2 · Ver el otro diagrama

La vista explota las piezas de una misma aplicación. El orden vertical expresa capas; las dependencias exactas son: presentación → infraestructura y aplicación; infraestructura → dominio y, desde el Worker, aplicación; aplicación → dominio.

Contratos que cruzan las capas

File → Entradas tipadas → Analisis / EntradaPropuestaCosto / EntradaPropuestaMeta → PropuestaCosto / PropuestaMeta.

El nivel 1 se calcula desde la interfaz en el hilo principal. Los dos casos de uso de nivel 2 se ejecutan en un Worker local, con revisión, modalidad y entrada explícitas.

Reglas compartidas

numeric.ts centraliza aritmética decimal y fechas. proposalSearch.ts limita la búsqueda y calcula cupos. proposalValidation.ts verifica las asignaciones finales. risk.ts resume costo, crecimiento y volatilidad. projection.ts simula los escenarios.

Aplicación y dominio no importan React, Zod ni lectores de archivos. Las vistas formatean los resultados del motor.
